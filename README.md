# StormWatch 
v.0.1

🌩️ StormWatch

StormWatch é um projeto desenvolvido em Java com o objetivo de coletar, processar e apresentar informações meteorológicas, com foco no monitoramento de condições severas como chuvas intensas, tempestades, ventos fortes e outros eventos meteorológicos.

O projeto está sendo desenvolvido progressivamente conforme avanço nos meus estudos de Java e desenvolvimento Backend, servindo tanto como aplicação prática dos conceitos aprendidos quanto como projeto de portfólio.

🎯 Objetivo do projeto

O objetivo do StormWatch é construir uma aplicação capaz de consultar dados meteorológicos reais e transformá-los em informações úteis para acompanhamento das condições do tempo.

Inicialmente, o projeto terá foco no Brasil, principalmente no estado do Paraná.

Conforme o desenvolvimento avançar, a ideia é incluir recursos como:

🌡️ Consulta de temperatura

🌧️ Monitoramento de chuva

💨 Velocidade e direção do vento

⛈️ Identificação de condições favoráveis a tempestades

⚠️ Alertas meteorológicos

📍 Consulta por cidade ou coordenadas

📊 Histórico e visualização de dados

🗺️ Informações meteorológicas por região

🌪️ Monitoramento de eventos meteorológicos severos
